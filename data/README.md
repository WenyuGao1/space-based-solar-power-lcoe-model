# Data Guide

This directory keeps source evidence, model assumptions and generated results separate so the analysis can be audited.

## Contents

- `sbsp_parameters.csv`: reference values, explored ranges, improvement directions and source labels for every model parameter.
- `source_registry.csv`: source metadata and links.
- `uk_generation_costs.csv`: generation-only UK cost benchmarks.
- `uk_system_adjusted_costs.csv`: indicative system-adjusted comparison ranges.
- `assumptions.csv`: assumption classification and interpretation.
- `raw/`: official source workbooks retained in their original file format.
- `processed/`: deterministic outputs regenerated by `analysis/run_full_analysis.py`.

## Interpretation

Many SBSP architecture inputs are exploratory because no commercial-scale system has been deployed. A source label identifies where a value or range was informed; it does not turn an exploratory architecture assumption into an observed cost.

The benchmark files intentionally distinguish generator-boundary LCOE from broader system-adjusted comparisons. Values with different real-price bases are labelled rather than silently normalised.
